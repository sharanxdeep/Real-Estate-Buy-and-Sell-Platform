## 📖 About

A property marketplace where users can list homes and apartments for sale or rent, browse active listings, and connect with sellers — built with a separate `client` (React frontend) and `api` (Node/Express backend).

## ✨ Features

- 🏠 Create, browse, and manage property listings
- 🔍 Search and filter properties
- 👤 User authentication and profiles
- 💬 Contact/inquiry flow between buyers and sellers
- 📱 Responsive UI across devices
